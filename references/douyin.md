# 抖音动画短视频：镜头、字幕与验收

以下时长和布局是制作启发与起始配置，不是平台推荐算法或官方安全区规范。具体平台上传规则、界面遮挡和账号数据在制作时核实，不把 TikTok 广告规格当成抖音自然流量规则。

## 内容与镜头

- 先用一个具体问题、异常、动作或结果建立观看理由。可以尝试前 1–3 秒呈现核心矛盾，再用实际回放与账号数据判断，不承诺某个秒数提高流量。
- 每个镜头只设一个主要焦点；动作揭示机制，文字帮助命名和记忆。
- 以新信息、因果变化、角色反应或细节揭示推动时间轴。保留有作用的理解停顿，不按固定秒数强制切镜或堆转场。
- 科普可采用“问题 → 机制演示 → 应用/结论”；角色故事可采用“目标 → 阻碍 → 行动 → 转折/结果”。结尾兑现开头。AI 科普类默认在结论之后加入“关注我，掌握更多AI知识”，同时写入 SCRIPT.md、分镜及最终字幕，纳入总时长；已有这句话时不重复添加。用户取消或另有结尾要求时覆盖默认，非 AI 科普题材按需要使用 CTA。
- 音效跟随有意义的动作，不因没有 BGM 就自动加入密集 SFX。

## 分镜字段与连续性

表格至少包含：镜头 ID / 时间 / 旁白或对白 / 主体动作 / 景别与镜头运动 / 观众焦点 / 连续性锚点 / 验收标准。

角色类在开始制作前写设定表：外观与比例、主色、服装、道具、可用表情/姿态、背景、运动方向。镜头变化时追踪道具状态、人物位置、视线与因果关系。科技图解也追踪同一对象的颜色、符号与状态。

复杂镜头用低成本动态分镜验证动作和切镜，临时旁白要标注为临时。预览关注“看懂什么变化”，而不是“多少个元素在动”。

## 中文字幕配置

项目根目录可放 ai-video.config.json。下列配置针对 1080×1920，只是避让的保守起点；按实际 UI、字体和 frame.md 修改：

~~~json
{
  "captions": {
    "font_family": "Microsoft YaHei",
    "font_size": 64,
    "theme": "dark",
    "background": "transparent",
    "top": 1382,
    "width": 778,
    "line_height": 1.3,
    "max_units_per_line": 12,
    "max_lines": 2,
    "min_duration": 0.18,
    "max_duration": 3
  }
}
~~~

- font_family 是本机实际安装的单个字体族；声明中还包含 Noto Sans SC/PingFang SC 回退。跨机器交付先验证字体，正式可复现交付宜打包可分发的字体并调整字体声明。
- max_units_per_line 是合成前的保守字宽预算；浏览器使用实际字体 measureText 重新换行。
- 字幕最多指定行数，一个词条超过预算时调整字体/预算，或修改口播重新合成；缺失或不可靠的时间戳重新获取或实际对齐。保持词条完整，不手改或编造逐字时间。
- 字幕默认随视频风格调整：制作代理读取 frame.md 后把实际 CJK 字体、字号、颜色写入配置，不只修改设计文字。theme=dark 用于深色画面，默认浅色字和轻阴影；theme=light 用于浅色画面，默认深色字。color 可覆盖文字色以匹配主视觉。风格映射由代理完成，适配器不自动解析 frame.md 或继承英文 preset skin。
- 默认 background=transparent，不加底色条。复杂画面需要衬底时，优先调整字幕位置，必要时用淡色半透明底，例如 rgba(255,255,255,.16)，并选足够清晰的字色；默认不使用不透明黑底。不要因加入底色遮挡主体。
- 省略 left 时按实际 width 自动水平居中，文本也居中；top 控制纵向字幕位置，默认位于画面下部并避让主体与平台 UI。仅用户明确要求偏移时设置 left。既有工程的遗留偏左/黑底配置应按当前默认更新，用户明确选择的样式优先。
- min_duration 是最低可读显示窗口的起点。实际可读性还受文字长度影响，手机实时回放后调整节拍和分组。
- 字幕运行时默认从 jsDelivr 加载固定 GSAP 版本。离线项目把对应脚本放到 assets/vendor/gsap.min.js，并在 captions 中设置 gsap_src 为该项目内相对路径；生成器会检查文件并固定其完整性哈希。

## 实际字体检查

在 HyperFrames 预览中，用浏览器读取：

~~~javascript
window.__aiCaptionQA
~~~

结果必须 ready=true，errors=[]。错误条目携带 group ID 和 frame，可定位具体镜头。发现超过行宽/行数时，调整分组预算、字体或口播节拍，重新生成字幕；不把超出的第三行藏起来。

## UI 遮罩与移动端回放

预览临时叠加平台 UI 遮罩，涵盖右侧按钮、底部账号/描述、顶部控件和实际字幕区域。遮罩属于检查层，导出时移除；不得把示意坐标标为官方安全区。

按 360–430 CSS 像素宽的手机预览检查大致观看尺度，再看全分辨率截图。主角面部、核心动作、关键数字和字幕均应避开遮挡。静音回放能理解核心变化；有声回放检查自然度、气口和同步。

## QA.md

记录 CLI 版本、依赖版本、分镜/旁白/字幕数量、各检查退出码、预览时间点、字幕实际宽度 verdict、手机回放结果、最终 MP4 实测规格和声音检查。

镜头/转场问题用“镜头 ID + 时间 + 具体表现”记录。任何 check 豁免均附截图与实时回放证据，并明确检查本身未通过。正常交付优先修复错误，不按时间窗口一律豁免。

导出后再听成片，检查首尾、每个切镜、重复音轨、黑帧、字幕缺失、冻结和静音。计划中的停顿/黑场要与异常区分记录。
